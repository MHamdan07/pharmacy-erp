# 12 Cashier Module & High-Speed POS

## Overview
The Cashier Module provides a touch-friendly Point of Sale (POS) billing terminal designed for fast retail checkout.

## Terminal Features
- **Barcode & QR Scanner**: Instant item lookup using 1D/2D scanners.
- **Visual Quick Keys**: Touch grid pills for top-selling OTC products.
- **Generic Search**: Search by active ingredient with live stock count.
- **Multi-Payment & Split Billing**: Cash, Card, JazzCash, EasyPaisa, and partial split payment.
- **Thermal Receipt Printing**: 80mm ESC/POS thermal printing with QR verification code.
