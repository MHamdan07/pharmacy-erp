# 14 Admin Module & Super Admin Dashboard

## Overview
The Admin Module governs global SaaS platform operations for **Super Admins** and tenant-level administrative controls for **Company Owners**.

## Dashboard Controls
- **Tenant Management**: Onboard new pharmacy companies, set subscription tiers, and freeze/activate accounts.
- **Global Financial Metrics**: Monthly Recurring Revenue (MRR), total active branches, and transaction volume.
- **Security & Audit Logs**: Immutable audit trail capturing logins, role modifications, and inventory overrides.
- **Database Snapshot Backups**: Automated daily MongoDB Atlas backups with 1-click restore.
