# 26 Maintenance & System Operations

## Overview
System Maintenance ensures 99.9% uptime, zero-downtime database migrations, automated log rotation, and serverless health monitoring.

## SOPs
- **Database Maintenance**: Weekly index optimization and automated Cloudinary artifact cleanups.
- **Log Management**: Audit logs retained for 365 days with compression.
- **Security Updates**: Bi-weekly npm security vulnerability audits (`npm audit`).
