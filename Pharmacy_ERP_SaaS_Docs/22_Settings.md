# 22 System Settings & Thermal Receipt Config

## Overview
The Settings Module manages tenant-wide operational parameters, thermal receipt templates, tax configurations, and system defaults.

## Configuration Parameters
- **Company Branding**: Logo, store header title, tagline, tax ID (NTN/VAT).
- **Thermal Receipt Formatter**: Customize receipt width (80mm / 58mm), header note, footer return policy text, and QR code verification toggle.
- **Tax & Currency Settings**: Default currency symbol (`$`, `PKR`, `AED`), VAT rate, tax inclusion rule.
- **System Automation**: Auto-quarantine expired batches toggle, low stock notification threshold.
