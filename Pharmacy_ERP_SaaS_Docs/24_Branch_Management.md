# 24 Branch Management & Multi-Outlet Operations

## Overview
The Branch Management Module enables pharmacy enterprises to manage multiple retail outlets, hospital outlets, and warehouse distribution centers under a single corporate tenant.

## Capabilities
- **Branch Directory**: Create physical outlets with branch code (`BR-001`), address, phone, and assigned branch manager.
- **Branch Context Switcher**: Top-header dropdown allowing Owners/Admins to switch active branch view dynamically.
- **User Branch Scoping**: Restricts Cashiers and Inventory Staff to operating strictly within assigned branches.
- **Inter-Branch Stock Transfers**: Request, approve, dispatch, and receive inventory transfers between branches with automated batch tracking.
