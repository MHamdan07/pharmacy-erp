# 09 Purchase Order & Stock Receiving

## Overview
The Purchase Module handles purchase order (PO) generation, supplier order placement, stock receiving verification, batch creation, and accounts payable ledger entries.

## Workflows
- **Purchase Order (PO) Creation**: Select vendor, add medicines, target branch, expected delivery date, and agreed wholesale unit price.
- **Stock Receiving Verification**: Match delivered physical items against PO line items. Generate batch numbers and expiry dates.
- **Automatic Stock Inflow**: Receiving PO approval automatically updates batch inventory balances.
- **Accounts Payable**: Record supplier invoices, payment terms (Net 30, COD), and partial/full payment vouchers.
