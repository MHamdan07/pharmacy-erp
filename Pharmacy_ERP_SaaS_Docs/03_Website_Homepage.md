# 03 Website Homepage & Public Landing Portal

## Overview
The Website Homepage provides a high-converting public landing portal showcasing system capabilities, multi-tenant features, live pricing, and direct links to the customer e-storefront and sign-in portal.

## Section Breakdown
1. **Header Navigation**: Gradient logo (`Pharmacy ERP`), Feature links, `E-Storefront` link (`/store`), `Sign In` button (`/login`), and `Onboard Pharmacy` CTA.
2. **Hero Section**: Value proposition headline, subheadline, visual UI mockups (POS billing, AI OCR scanner, FEFO expiry warning), and dual CTA buttons.
3. **Feature Cards**: FEFO batch control, AI prescription OCR, high-speed POS, customer storefront, multi-branch transfers, and 2FA security.
4. **Live Portals**:
   - Customer Storefront: `https://pharmacy-erp-rouge.vercel.app/store`
   - Owner Login Portal: `https://pharmacy-erp-rouge.vercel.app/login`
