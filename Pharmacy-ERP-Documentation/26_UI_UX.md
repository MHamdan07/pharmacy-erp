# 26 UI/UX & Design System

## Overview
The UI design system adheres to a modern, medical-grade dark theme tailored for high-density information displays, low eye strain in clinical environments, and rapid touch navigation.

## Design Tokens
- **Primary Accent**: `#2563EB` (Medical Blue)
- **Success Accent**: `#16A34A` (Clinical Green)
- **Warning Accent**: `#D97706` (Amber / Expiry Warning)
- **Danger Accent**: `#DC2626` (Red / Interaction Warning)
- **Background**: `#0F172A` (Slate Dark)
- **Typography**: Inter (Google Fonts) with 8px Grid Spacing System
