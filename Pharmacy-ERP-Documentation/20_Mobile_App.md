# 20 Mobile App & PWA Strategy

## Overview
The Mobile Strategy provides a Progressive Web App (PWA) and React Native mobile extension for delivery agents, pharmacy managers on the move, and retail patients.

## Capabilities
- **Delivery Mobile App**: GPS route navigation, digital signature capture, proof of delivery upload, offline order sync.
- **Manager Mobile Dashboard**: Real-time sales summary, low stock push notifications, and quick stock transfer approvals.
- **Patient PWA Storefront**: Mobile-first design for `/store` with camera-based prescription scanning and order tracking.
