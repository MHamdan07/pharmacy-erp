# Pharmacy ERP Frontend

This frontend is built with React and Vite.

## Run the frontend

From the frontend folder:

```bash
npm install
npm run dev
```

The app will be available at:
- http://localhost:5173

## Build for production

```bash
npm run build
```

## Notes

- The frontend expects the backend API to be running at http://localhost:5000.
- If you changed the backend port, update the API base URL in the frontend config.
